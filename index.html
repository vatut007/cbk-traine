Запомните

Заглавные буквы и есть код числа. Когда будете готовы, начните тест: числа пойдут в случайном порядке, пока не нажмёте «Хватит».

Напишите слово для числа

Фразы из длинных чисел

Число разбивается на куски из списка (1, 2 или 3 цифры). Составьте фразу, в которой по порядку есть слово для каждого куска. Слова можно склонять, а между ними вставлять любые связки («у», «на», «большой»).
